# template-literals
A simple tool to convert JavaScript template literals to normal strings

## How to use?
The easiest way is to visit [https://swiatekf361.github.io/template-literals](https://swiatekf361.github.io/template-literals), paste your code and hit Convert.

You can also:
- Take a look at [`literals.js` content](https://github.com/swiatekf361/template-literals/blob/main/literalsjs.js),
- Read [changelog](https://github.com/swiatekf361/template-literals/blob/main/CHANGELOG.md),
- Add an [issue](https://github.com/swiatekf361/template-literals/issues/),
- Check [Python version](https://github.com/swiatekf361/literals-python/)
